## Правило работы

Перед продолжением работы читать этот файл и после изменений обновлять его. История решения и подробные критерии — в `PROJECT_HANDOVER.md`. Структурный граф — `graphify-out/`, команды ниже.

## Что делаем

Строим каталог мобильных digital invitation templates. Каждый шаблон называется только числом: первый — `1`, следующий — `2` и т. д.

## Что уже сделано

- Шаблон **`1`** находится в `templates/1/`; его URL — `/templates/1/`.
- Runtime берёт `demo.json`; metadata — `template.json`; каталог — generated manifest.
- Имена пары — только разрешённые PNG/RGBA. Все прочие данные приглашения — live HTML/CSS.
- Есть Vite-сборка и production-copy локальных template assets.
- **Vercel используется для этого проекта**. Аккаунт пользователя уже создан; повторная регистрация не нужна. На этой машине нет сохранённой CLI-сессии, поэтому связать папку с Vercel-проектом можно сразу после одного входа в существующий аккаунт; deploy не выполнялся.
- Graphify установлен локально для карты структуры. `npm run graph:update` пересобирает Graphify и инвентарь файлов, а `npm run graph:watch` делает это автоматически после любого изменения.
